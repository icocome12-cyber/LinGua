# LinGua app structure

This app is organized into a clean screen structure while keeping the original HTML screens intact for compatibility.

## App shell

- `app/index.html` — app entry point
- `app/landing/index.html` — landing page
- `app/onboarding/language.html` — language selection
- `app/onboarding/profile.html` — learner profile
- `app/onboarding/ready.html` — onboarding complete
- `app/learn/index.html` — learn home
- `app/learn/stage-1.html` — stage 1
- `app/lesson/vowels.html` — lesson flow
- `app/lesson/complete.html` — completion screen
- `app/practice/index.html` — practice hub

## Legacy screens preserved

The original generated-screen folders remain in place so existing relative links and design files continue to work while the app is being normalized.
